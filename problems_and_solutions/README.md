# Sample mySQL problems and solutions

For a list of problems and solutions, please refer to the [problems_and_solutions](./docs/mysql_employees_50_practice_problems.pdf) File.

## How the problems and solutions are structured

The problems are structured in a way that they are grouped by the type of SQL operation they require and the solutions are provided in a solutions.sql file. Each problem is numbered and includes a description of the task to be performed, along with an expected output image for reference and are contained in problems.md files

## How the project is expected to be completed

The project is expected to be completed by phases beginning with the first phase of filtering and functions, followed by aggregation and grouping upto to last phase of indexing and optimization as based in the order of problems in the document
